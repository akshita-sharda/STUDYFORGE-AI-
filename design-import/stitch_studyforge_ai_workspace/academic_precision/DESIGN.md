## Brand & Style

This design system establishes an intellectual sanctuary engineered specifically for technical rigorous disciplines like Computer Science and Engineering. It steers clear of playful edtech gamification or cold, sterile enterprise SaaS. Instead, the design language reflects quiet authority, mental clarity, and tactile precision—reminiscent of a modern, well-curated university library combined with high-grade developer tools.

### Visual Style
The aesthetic blends **Modern Academic Minimalism** with **Tactile Utility**:
- **Restraint Over Decoration:** Surfaces avoid unmotivated gradients and hyper-saturated blurs. Every visual weight tier serves a functional mental model.
- **Micro-tactility:** Controls feel engineered. Subtle hairline borders (`1px`) frame elevated surfaces, accompanied by ultra-diffused, ambient drop shadows that simulate stacked archival index cards and precision instruments.
- **Calm Focus:** Expansive whitespace paired with warm paper-like ivory tones decreases retinal fatigue during marathon coding, proof-reading, and algorithmic design sessions.

### Color Distribution
Surfaces rely on tonal balance: 75% warm neutral canvas, 20% crisp structural cards, and 5% strategic lavender and semantic accents. Semantic colors should never compete; use tinted background containers for tags and code contextual blocks, applying full-intensity color strictly to text indicators or iconography.

## Typography

Typography acts as a direct conduit for comprehension. Geist provides systematic legibility with minimal visual noise for reading theory, summaries, and lecture notes. JetBrains Mono grounds the workspace in engineering authenticity for code, keyboard shortcuts, metadata markers, and tabular data.

### Implementation Rules
- **Mathematical & Structural Headers:** Maintain tight negative letter tracking on headings (`-0.02em` to `-0.03em`) to anchor cognitive focus.
- **Code & Metadata:** All system tags, timestamp badges, runtime logs, and algorithm metrics must strictly render in `JetBrains Mono` with uppercase tracking (`letter-spacing: 0.04em` or above).
- **Prose Reading Comfort:** `body-md` is calibrated at `0.9375rem` (15px) with a generous `1.55` line height, optimizing eye tracking across dense technical documentation.

## Layout & Spacing

The workspace prioritizes vertical flow and content-centric horizontal breathing space, dispensing with vertical sidebars in favor of a full-width panoramic canvas.

### Layout Model
- **Grid Architecture:** 12-column layout with a maximum centered container width of `1440px`.
- **Top Bar Anchorage:** The header spans edge-to-edge with sticky elevation, housing all global navigation, AI prompt triggers, and student status.
- **Main Workspace Canvas:** Structured with a split pane or multi-column card arrangement (e.g., Code Notebook left, AI Co-pilot right) adhering to a 60/40 or 50/50 relational split.

### Breakpoints
- **Desktop (1024px and above):** 12 columns, `margin: 2.5rem`, `gutter: 1.5rem`.
- **Tablet (768px – 1023px):** 8 columns, `margin: 1.75rem`, `gutter: 1rem`. Two-column study splits gracefully collapse into vertically stacked panels with switchable tabs.
- **Mobile (Below 768px):** 4 columns, `margin: 1.25rem`, `gutter: 1rem`. Pill navigation shifts into an off-canvas drawer or consolidated horizontal snap-scroller.

## Elevation & Depth

This system avoids dramatic heavy shadows, utilizing high-clarity structural delineation reminiscent of fine paper leaves and precision desk accessories.

### Depth Hierarchy
- **Base Level (Canvas):** Pure `#FAF9F6` (`#18161F` Dark) with zero elevation.
- **Tier 1 (Surface Cards & Editor Panels):** `#FFFFFF` (`#221F2C` Dark), bounded by a `1px` border of `#E8E5DF` (`#2F2B3D` Dark) and supported by an ultra-soft ambient shadow:
  `box-shadow: 0 1px 3px rgba(41, 39, 53, 0.03), 0 4px 12px rgba(41, 39, 53, 0.02);`
- **Tier 2 (Floating Floating Action Palettes & Hovered Cards):**
  `box-shadow: 0 4px 16px rgba(41, 39, 53, 0.06), 0 1px 2px rgba(41, 39, 53, 0.04);`
- **Tier 3 (Dropdown Menus, Modals & Floating AI Drawers):**
  `box-shadow: 0 12px 32px -4px rgba(41, 39, 53, 0.12), 0 4px 12px -2px rgba(41, 39, 53, 0.04);`
  Includes a subtle backdrop blur (`backdrop-filter: blur(8px)`) when overlaid on code or notes.

### Dark Mode Elevation
Shadows in dark mode shift from dark occlusion to layered surface lumination: borders lighten slightly (`#3E3950`), and surfaces step up sequentially (`#18161F` -> `#221F2C` -> `#2A2637`).

## Shapes

The geometry strikes a deliberate synthesis between structured academic rigor and humanistic warmth:
- **Structural Containers (Cards, Code Blocks, Modals):** Use `0.75rem` (`rounded-md` to `rounded-lg`) corner radii to maintain clean architectural lines.
- **Interactive Controls (Navigation Buttons, Action Badges, Filters):** Full pill curvature (`9999px`) provides clear tactile contrast between fixed workspace containers and clickable operational tools.
- **Micro-elements (Checkboxes, Inputs, Tooltips):** `0.375rem` to `0.5rem` (`rounded-sm` to `rounded-md`) ensuring compactness without visual severity.

## Components

### 1. Horizontal Navigation & Pill System
- **Navigation Bar:** Elevated pinned header with a persistent height of `64px`, bottom-bordered with `#E8E5DF` (`#2F2B3D` in Dark Mode).
- **Pill Buttons:** Height `36px`, horizontal padding `1rem`, `font-size: 0.875rem`, weight `500`.
  - *Default State:* Transparent background, `#6E697F` text.
  - *Hover State:* Background `#F0EEE9` (`#2A2637` Dark), text `#292735` (`#ECE9F2` Dark).
  - *Active / Selected State:* Background `#7364C7` (Primary Lavender), text `#FFFFFF`, with smooth micro-transition (`150ms ease-out`).
- **Dropdown (Study Tools):** Triggered by a pill with a mini chevron. Renders a Tier-3 overlay panel with structured categories (e.g., "Complexity Visualizer", "Formula Engine", "Mock Viva").
- **Theme Switcher & Profile:** Contained inside an organic segmented capsule on the right: a two-segment icon toggle for Dark/Light, and a `32px` circular student avatar with an active status dot in Sage Mint.

### 2. Buttons & Actions
- **Primary Action Button:** Solid `#7364C7` fill, white text, pill-shaped, subtle inset top highlight (`inset 0 1px 0 rgba(255,255,255,0.2)`).
- **Secondary Action Button:** Surface-matched fill (`#FFFFFF`), `1px` border `#E8E5DF`, `#292735` text. On hover: border-color `#7364C7`, text `#7364C7`.
- **Ghost/Tertiary:** No border or fill, `#6E697F` text, shifts to tinted background `#E8F5F0` or `#EFF6FD` on hover depending on contextual semantics.

### 3. Cards & Code Sandboxes
- **Academic Workspace Cards:** White surface with standard hairline outline. Padding strictly `1.5rem`.
- **Code Snippet Modules:** Distinct background tone `#1E1B29` in both light and dark modes to maintain syntax consistency. Wrapped in a `12px` rounded card with top metadata header: language tag in `JetBrains Mono` (`label-sm`), execution time pill, and a copy button.

### 4. Chips & Metadata Badges
- **Shape:** Height `24px`, fully rounded pill (`9999px`), padding `0.25rem 0.625rem`.
- **Typography:** `label-md` using `JetBrains Mono`.
- **Theming Variants:**
  - Sage (Completed/Passed): Text `#2E6850`, background `#E8F5F0`.
  - Lavender (Active Module): Text `#584AA3`, background `#F1EEFA`.
  - Peach (Bug/Exam Prep): Text `#9E4C33`, background `#FDF0EC`.

### 5. Form Controls & Search
- **AI Prompt & Inputs:** Height `44px`, background `#FFFFFF` (`#221F2C` Dark), border `1px solid #E8E5DF` (`#2F2B3D` Dark).
- **Focus State:** Border shifts cleanly to `#7364C7` with a non-intrusive outer ring (`box-shadow: 0 0 0 3px rgba(115, 100, 199, 0.15)`).
- **Checkboxes & Radios:** `18px` structural square with `4px` radius or circle. Checked state fills with `#7364C7` and a crisp white tick mark.
