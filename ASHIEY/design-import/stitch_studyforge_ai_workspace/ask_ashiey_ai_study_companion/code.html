Can you calculate the Effective Memory Access Time (EMAT) step-by-step? Assume a Translation Lookaside Buffer (TLB) search latency is 20 ns, main memory access time is 100 ns, and the TLB hit ratio is 85%. Also, what happens if we have a two-level page table on a TLB miss?

Here is the step-by-step rigorous calculation for Effective Memory Access Time (EMAT). Under hardware paging architectures, the translation lookup happens either via high-speed associative registers (TLB) or by walking hierarchical page tables residing in main DRAM.

calculate Governing Equation General Paging Model
EMAT = α × (tTLB + tmem) + (1 - α) × (tTLB + (k + 1) × tmem)
• α (Alpha) = TLB Hit Ratio (Probability of TLB cache hit)
• tTLB = Associative lookup latency
• tmem = Main memory access cycle time
• k = Number of levels in hierarchical page table

Execution with Given Parameters

Input Variables α = 0.85 (85%) tTLB = 20 ns tmem = 100 ns
Case A: TLB Hit (85%) TLB check + 1 memory reference to read requested operand: 20ns + 100ns = 120 ns
Case B: TLB Miss (15%) For standard single-level paging (1 page table read + 1 data read): 20ns + 200ns = 220 ns
Step-by-step Substitution:
1. EMATsingle-level = [0.85 × (20 + 100)] + [0.15 × (20 + 2 × 100)]
2. EMATsingle-level = [0.85 × 120 ns] + [0.15 × 220 ns]
3. EMATsingle-level = 102.0 ns + 33.0 ns = 135.0 ns
check_circle Single-Level Result Verified: 135.0 ns
+35.0% latency penalty over raw memory
account_tree Answer to follow-up: Two-Level Hierarchical Paging (k = 2)

When a TLB miss occurs with a 2-level paging scheme, the memory management unit must access the Outer Page Directory (100 ns), the Inner Page Table (100 ns), and finally the actual Physical Memory Frame (100 ns).

EMAT2-level = 0.85 × (20 + 100) + 0.15 × (20 + 3 × 100) = 102 ns + 48 ns = 150.0 ns

// Calculates Effective Memory Access Time in nanoseconds
double calculate_emat(double tlb_hit_ratio, double tlb_latency, double dram_latency, int pt_levels) {
    double hit_time  = tlb_latency + dram_latency;
    double miss_time = tlb_latency + ((pt_levels + 1) * dram_latency);
    return (tlb_hit_ratio * hit_time) + ((1.0 - tlb_hit_ratio) * miss_time);
}

int main() {
    double emat_1 = calculate_emat(0.85, 20.0, 100.0, 1);
    double emat_2 = calculate_emat(0.85, 20.0, 100.0, 2);

    std::cout << std::fixed << std::setprecision(1);
    std::cout << "EMAT Single Level: " << emat_1 << " ns\n"; // Output: 135.0 ns
    std::cout << "EMAT Two Level:   " << emat_2 << " ns\n"; // Output: 150.0 ns
    return 0;
}
